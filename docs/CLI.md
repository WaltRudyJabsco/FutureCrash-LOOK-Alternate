# Alternate 4.0.0 command registry

Generated by `python3 tools/command_reference.py`; use `--check` to detect drift.

Captured from executable help using an isolated home directory.

## -m look lk commands

```text

Files
  lk detail [PATH|WORD]                                interactive detail view
  lk dirs [PATH|WORD]                                  interactive dirs view
  lk files [PATH|WORD]                                 interactive files view
  lk tree [PATH|WORD]                                  interactive tree view
  lk recent [PATH|WORD]                                interactive recent view
  lk size [PATH|WORD]                                  interactive size view
  lk cp SRC... DEST                                    copy (never overwrites; clashes get ' copy')  (copy)
  lk mv SRC... DEST                                    move or rename (refuses to overwrite)  (move)
  lk rm PATH...                                        remove to LOOK's trash (undoable)  (remove)
  lk mk PATH | DIR/                                    make a file, or a folder when it ends with /  (make)
  lk undo [list|skip|ID]                               reverse the newest change made by LOOK, LO or the filer
  lk journal [N]                                       what LOOK, LO and background jobs actually did  (receipts)
  lk open PATH                                         open in its desktop app
  lk preview PATH                                      quick external preview
  lk reveal PATH                                       show in Finder / the file manager
  lk find WORD                                         find names under your home folder

LO & models
  lk models [NAME]                                     choose the model LO and Future Crash share  (ollama models)
  lk hosts [use NAME | add NAME URL | forget NAME | discover] where inference runs (local, desktop over Tailscale…)  (ollama host, ollama hosts)
  lk access [conservative|workspace|power|unsafe]      LO's default permission profile  (ollama access)
  lk grants [revoke PATH]                              folders LO may reach outside its workspace
  lk personality [NAME]                                LO's voice (never its permissions)
  lk thinking [light|adaptive|deep]                    reasoning depth
  lk web [key|status|forget]                           Ollama web-search key (stored machine-locally, 0600)  (ollama key)
  lk tools                                             every tool LO can be offered, with what it needs
  lk vision IMAGE [QUESTION]                           ask a vision model about an image
  lk benchmark [--all]                                 speed and tool-calling check for your models  (ollama test)
  lk ai [status|start|stop]                            the inference lane, background queue and looked

Memory & craft
  lk memory [add TEXT | forget TEXT | clear | clear-recent | path] [--mind future-crash] what LO remembers about you
  lk forget TEXT                                       forget memories containing TEXT
  lk skills [add TEXT | forget TEXT | clear-learned | update | path] how LO does its job (skills.md)

Machine
  lk machine                                           machine summary  (box)
  lk ports                                             listening ports and their owners  (up)
  lk port NUMBER                                       who is on a port
  lk processes [NAME|PID]                              processes by CPU  (procs, process, proc, pid)
  lk disk                                              storage
  lk gpu                                               graphics / accelerator
  lk git [PATH]                                        repository state
  lk run [PATH]                                        how to run the project here  (project)
  lk env [FILTER]                                      environment variables (secrets masked)
  lk path                                              PATH entries, in order, and whether they exist
  lk why COMMAND                                       how a command name resolves

Network
  lk net                                               addresses, Tailscale and inference reachability  (network, tailscale)

Schedules & jobs
  lk schedule [add (--every 2h|--daily 09:00|--in 10m) PROMPT | rm ID | pause ID | resume ID] prompts that run later or on a rhythm (shared with Future Crash threads)
  lk jobs [N]                                          background LO results

Settings & profile
  lk settings                                          every preference in one place  (config)
  lk set KEY VALUE                                     change one setting
  lk profile [backup DEST | export FILE | restore SOURCE | import-3x [--dry-run]] your portable LOOK
  lk apps [CATEGORY APP]                               which desktop app opens video, audio, image, document, text
  lk feedback [sound on|off | motion off|subtle|normal | demo] semantic sound and motion  (sound)
  lk shell-init zsh|bash                               print shell integration (eval it from your rc file)

LOOK itself
  lk help [all]                                        the few entrances worth remembering
  lk commands                                          searchable palette of every command
  lk version                                           print version  (--version, -V)
  lk log [N]                                           the diagnostic log
  lk doctor                                            check everything LOOK depends on
  lk uninstall                                         remove the program (your profile stays unless you say so)

Extras
  lk media [toggle|next|prev|stop]                     control the music already playing  (music)

lo [--conservative|--workspace|--power|--unsafe] [@host] [search] [PROMPT]  ·  lo bg PROMPT  ·  future-crash
```
